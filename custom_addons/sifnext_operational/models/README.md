# SIFNEXT Operational

Starter Odoo 19 addon for the SIFNEXT integrated ERP MVP.

## Install
Copy this folder into the SIFNEXT Odoo `addons` directory, update the Apps list,
then install **SIFNEXT Operational**.

This starter is intentionally separate from the previous `ksg_sales` / `ksg_operational`
project. The business fields and workflow can be expanded from the SIFNEXT MVP Operational flow.
