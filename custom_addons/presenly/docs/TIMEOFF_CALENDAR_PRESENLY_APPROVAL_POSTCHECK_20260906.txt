PURPOSE
- Replace the native Approve/Refuse buttons on the Time Off Overview calendar
  popup (`/odoo/time-off-overview`) with Presenly Approval actions.
- Keep Presenly Approval Routes as the single approval path everywhere.

ROOT CAUSE
- `/odoo/time-off-overview` uses model `hr.leave.report.calendar`, not
  `hr.leave`.
- `hr.leave.report.calendar` is a SQL view with its own footer buttons:
  - action_approve (native)
  - action_refuse (native)
- Those buttons were controlled by the SQL-view model's `is_manager`, and were
  not affected by the `hr.leave` native can_* flag override from the previous
  rollout.

CHANGES
1. New model inherit file:
   custom_addons/presenly/models/presenly_report_calendar.py
   - `_inherit = 'hr.leave.report.calendar'`
   - Adds:
     - presenly_approval_state (related leave_id)
     - presenly_approval_progress (related leave_id)
     - presenly_can_approve (computed)
     - presenly_can_reject (computed)
     - action_presenly_approve()
     - action_presenly_open_reject_wizard()
2. New view inherit:
   custom_addons/presenly/views/hr_leave_report_calendar_views.xml
   - Hides native footer approve/refuse buttons.
   - Adds Presenly approve/reject buttons driven by presenly_can_* flags.
3. Registered new view in __manifest__.py.
4. Version bump to 19.0.13.3.0.
