PRESENLY OVERVIEW NATIVE APPROVAL HIDING — ROLLOUT POST-CHECK
Date: 2026-09-06
Database: odoo
Module: presenly 19.0.13.2.0

PURPOSE
- Remove the native Odoo Time Off approval affordances that still appeared on
  the Overview pages (My Time Off form/list/kanban).
- Keep Presenly Approval Routes as the single, user-facing approval path.

APPROACH
- Did not delete native views or buttons. Instead, the native computed flags
  that control their visibility are forced to False for Presenly-managed Time
  Off:
  - can_approve
  - can_validate
  - can_refuse
  - can_back_to_approve

CHANGES
1. `HrLeavePresenly` now overrides native `_compute_can_approve`,
   `_compute_can_validate`, `_compute_can_refuse`, and
   `_compute_can_back_to_approve`.
2. Each override calls `super()` and then sets the flag to False when
   `presenly_approval_engine == 'presenly'`.
3. Presenly workflow flags (`presenly_can_submit`, `presenly_can_approve`,
   `presenly_can_reject`, `presenly_can_cancel`) are unchanged.
4. Server-side guards (native `action_approve`, `_action_validate`,
   `action_refuse`, `action_back_to_approval` overrides) remain in place.

EFFECT ON UI
- On Presenly-managed Time Off:
  - Native "Approve" disappears from form header.
  - Native "Validate" disappears from form header.
  - Native "Refuse" disappears from form header.
  - Native "Back to Approval" disappears.
  - List/kanban native approve/refuse action buttons no longer show.
- Presenly buttons remain:
  - Submit for Approval
  - Approve Current Level
  - Reject
  - Cancel Request
