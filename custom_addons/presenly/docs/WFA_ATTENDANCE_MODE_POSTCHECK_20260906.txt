PRESENLY WFA ATTENDANCE AND MODE SELECTION — ROLLOUT POST-CHECK
Date: 2026-09-06
Database: odoo
Module: presenly 19.0.12.0.0

SCOPE
- Added Work From Anywhere (WFA) as an attendance mode.
- WFA is temporary-approval-free and informational only: it records that the
  employee is working from anywhere, with no geofence and no location limit.
- Added a mobile mode-selection endpoint.
- Added a dedicated mobile documentation file for mode selection.
- Kept native hr.attendance as the transaction source and kept the Presenly
  server as the owner of identity and timestamps.

MODEL CHANGES
hr.attendance gained:
- presenly_attendance_mode: Selection(location, wfa), default location.

presenly.attendance.event gained:
- attendance_mode: Selection(location, wfa).
- create_failed_event now records attendance_mode when the failed payload
  contains it.

Color semantics now treat WFA as not requiring a Work Location snapshot.
A WFA record is still red if successful check-in/check-out evidence is missing,
duration exceeds 16 hours, or the session is stale.

CONTROLLER CHANGES
New endpoint:
- POST /api/presenly/v1/attendance/modes (auth=session, readonly)

Existing endpoints extended:
- status now returns attendance_mode, can_select_mode, and wfa_available.
- can_check_in now allows WFA even when no scheduled/geofence-ready location.
- check-in accepts attendance_mode or legacy mode alias.
  - location: unchanged geofence path.
  - wfa: no geofence, no work location required, GPS and selfie optional.
- check-out derives mode from the active attendance and skips geofence and
  same-location checks for WFA; GPS/selfie are optional for WFA.
- _optional_coordinates validates partial GPS input; all-empty GPS is allowed.
- _requested_mode normalizes "wfa"/"work-from-anywhere" and
  "location"/"on-site"/"onsite".

UI CHANGES
- Attendance Context now shows Attendance Mode and Source.
- Attendance list and search expose Attendance Mode, WFA filter, and Mode grouping.
- Attendance Evidence list/form/search expose attendance_mode, WFA filter, and
  Mode grouping.
- Existing attendance records defaulted to location mode.
