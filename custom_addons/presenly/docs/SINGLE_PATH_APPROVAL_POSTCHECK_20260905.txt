ARCHITECTURE
- Presenly Approval Journey is the only approval path for Permission and Time Off requests.
- Permission remains presenly.permission.
- Time Off remains native hr.leave.
- Native hr_holidays remains the final engine for allocation, calendar leave, duration, and work-entry effects.
- Native Time Off approve/refuse/validate methods are guarded against bypass until the Presenly journey reaches a valid final state.
- Extra Hours approval remains native hr_attendance and is outside this journey.

APPROVAL SNAPSHOT
- presenly.approval.request stores the request-level journey.
- presenly.approval.step stores immutable level and assigned-approver snapshots.
- Rule or manager changes after submission do not change an active request.
- Only the assigned users of the current level may approve or reject.
- Reject requires a reason and closes all remaining levels.
- All configured levels are mandatory.
- A location-specific level overrides a company-wide level with the same sequence.
- Submission rejects missing, ambiguous, inactive, cross-company, or non-Presenly-Approver assignments.
