Date: 2026-09-06

PURPOSE
- Remove the misleading Approvals > My Approvals menu that produced
  "You don't have enough access rights to run this action."
- Keep Approval Journey data intact.
- Keep Time Off / Permission approval working directly from their forms.

ROOT CAUSE CONFIRMED
- The menu `My Approvals` pointed to a server action
  `action_server_presenly_my_approvals`.
- That server action had empty `group_ids`.
- Odoo's `_can_execute_action_on_records` falls back to
  `check_access("write")` on the action's model
  (`presenly.approval.request`) when `group_ids` is empty.
- Presenly Approver ACL for `presenly.approval.request` is read-only
  (write=False), so any Approver opening the menu got an AccessError.
- Approval from the Time Off form was never broken; the error was only on
  the menu action.

CHANGES
1. Disabled menus (active=False), not deleted:
   - Attendances > Approvals
   - Attendances > Approvals > My Approvals
   - Attendances > Approvals > Permission Approvals (already inactive)
   - Attendances > Approvals > Time Off Approvals (already inactive)
2. Added defensive `group_ids = Presenly Approver` to
   `action_server_presenly_my_approvals` so it would not demand write access
   if re-enabled later.
3. Version bump to 19.0.13.1.0.
