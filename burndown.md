## Criterio de actualizacion

Esta tabla debe actualizarse cuando una issue tenga evidencia concreta:

1. Commit o PR asociado.
2. Archivo publicado en el repositorio.
3. Enlace a GitHub Actions, artifact o Pages.
4. Comentario de cierre con evidencia.
