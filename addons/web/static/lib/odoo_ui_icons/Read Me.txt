The fonts in `fonts/` are generated, do not edit them by hand.  They are built
by `odoo/addons/web/tooling/icons/generate_icons.py` out of
`tooling/icons/odoo_ui_icons_config.json`, the Fontello project file the icon
set is maintained in: adding, redrawing or renaming an icon is editing that file
by re-exporting it from Fontello (https://fontello.com/) and running the script.
