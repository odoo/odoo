Contributing to Odoo
====================

[Full contribution guidelines](https://www.odoo.com/documentation/master/contributing/development.html)

TL;DR

* If you [make a pull request](https://www.odoo.com/documentation/master/contributing/development.html),
  do not create an issue! Use the PR description for that
* Issues are handled with a much lower priority than pull requests
* [Sign the CLA](https://www.odoo.com/sign-cla) before your contributions can be
  accepted. If you do not have a GitHub account, print the CLA, complete and
  sign it, and email it to `cla-submission@odoo.com`
* Pull requests must be made against the [correct version](https://www.odoo.com/documentation/master/contributing/development.html)
* There are restrictions on the kind of changes allowed in stable series, see
  the [contribution guidelines](https://www.odoo.com/documentation/master/contributing/development.html)
* Do not use pull requests to update translations; translations are managed
  through the [Odoo translation platform](https://www.odoo.com/translations)
