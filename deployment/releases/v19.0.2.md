## Migration / Upgrade

- **ไม่มี data migration** — รุ่นนี้ไม่มีการเปลี่ยน schema ที่ต้อง migrate ข้อมูล
- โมดูลใหม่ 3 ตัว ต้องติดตั้งด้วย `-i` (ถ้ายังไม่มีในฐานข้อมูล):

```bash
python odoo-bin -c /etc/odoo/odoo19.conf -d <DB> \
  -i od19_project_timesheet_billing,od19_web_navigation,od19_sales_customer_risk_gate \
  --stop-after-init
```

- โมดูลที่อัปเดต อัปเกรดด้วย `-u`:

```bash
python odoo-bin -c /etc/odoo/odoo19.conf -d <DB> \
  -u od19_website,od19_accounting_reporting,od19_reporting_jasper,od19_helpdesk_extension,od19_ui_defaults,od19_user_guide_tours \
  --stop-after-init
```
