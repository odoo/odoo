# คู่มือศึกษา: `account.group` กับ `account.account` (Odoo 19)

| หัวข้อ | รายละเอียด |
|---|---|
| เอกสาร | OD19-ACCT-GROUP-VS-ACCOUNT-GUIDE |
| เวอร์ชัน | R00 |
| วันที่ | 2026-11-05 |
| กลุ่มผู้อ่าน | ฝ่ายบัญชี / ผู้ใช้งานระบบบัญชี |
| ระบบ | Odoo 19 Community Edition |
| ฐานข้อมูลตัวอย่าง | `odoo19_puat` |

> **วัตถุประสงค์** — อธิบายให้ฝ่ายบัญชีเข้าใจความแตกต่างระหว่าง "บัญชี" (`account.account`) กับ "กลุ่มบัญชี" (`account.group`) ใน Odoo 19 โดยยกตัวอย่างจากผังบัญชีจริงของบริษัท เพื่อให้เลือกใช้งานบัญชีได้ถูกต้อง

---

## 1. ทำไมต้องรู้เรื่องนี้

ใน **Odoo 15** ผังบัญชีมีปุ่ม **"Is Account Control"** ทำให้แยกได้ว่า

- บัญชีที่เป็น "หัวข้อ" (Control) → **ลงรายการบัญชีไม่ได้** ใช้เป็นที่รวบรวมยอดเท่านั้น
- บัญชี "ปลาย" → ลงรายการได้

ใน **Odoo 19** แนวคิดนี้ **ถูกยกเลิกไปแล้ว** โดยแยกหน้าที่ออกเป็น 2 ส่วนชัดเจน

| หน้าที่ | สิ่งที่ใช้ใน Odoo 19 |
|---|---|
| ใช้ลงรายการ + มียอด + ส่งเข้า�รายงานการเงิน | `account.account` (บัญชี) |
| ใช้จัดกลุ่ม/เป็นหัวข้อในหน้าจอ | `account.group` (กลุ่มบัญชี) |

ผลที่ตามมา: **บัญชีทุกตัวใน Odoo 19 ลงรายการได้หมด** (รวมบัญชีหัวข้อเดิม) ดังนั้นต้องเข้าใจให้ดีเพื่อไม่ให้ลงรายการผิดบัญชี

---

## 2. รู้จักทั้งสองแบบ (ภาษาบัญชี)

| ประเด็น | `account.account` (บัญชี) | `account.group` (กลุ่มบัญชี) |
|---|---|---|
| คืออะไร | บัญชีแยกประเภทที่ใช้ลงรายการ | ป้าย/หัวข้อสำหรับจัดกลุ่ม |
| ลงรายการบัญชีได้ไหม | **ได้** | **ไม่ได้** |
| มียอดคงเหลือ (balance) ไหม | มี | ไม่มี |
| มี "ประเภทบัญชี" (asset/liability/.../expense) ไหม | มี (ตัวกำหนดว่ารายงานจัดเข้าไหน) | ไม่มี |
| ตั้งรหัสอย่างไร | กำหนดรหัสเองตรง ๆ | ผูกด้วย **ช่วงรหัส (prefix range)** |
| ปรากฏที่ไหน | ทุกหน้าจอ (ใบสำคัญ, รายงาน, ตั้งค่า) | หน้ารายชื่อบัญชี (ตัวเลือกจัดกลุ่ม) |
| เทียบกับ Odoo 15 | เหมือนบัญชีปลาย | เหมือนบัญชี Control / หัวข้อ |

**จำง่าย ๆ**
- `account.account` = **"บัญชีจริง"** — มีรหัส มีชื่อ มีประเภท มียอด
- `account.group` = **"ป้ายหัวข้อ"** — ใช้ติดป้ายให้บัญชีหลายตัวอยู่กลุ่มเดียวกัน ไม่มีตัวเลขของตัวเอง

---

## 3. กลไกการผูกกลุ่ม (เข้าใจได้ใน 1 นาที)

`account.group` ไม่ได้เป็น "พ่อแม่" ของบัญชีแบบผูกตรง ๆ แต่ใช้วิธี **กำหนดช่วงรหัส** ดังนี้

- กลุ่ม "เงินฝากออมทรัพย์" ตั้งช่วงรหัส start = `1113` ถึง end = `1113`
- บัญชีใดที่มีรหัส **ขึ้นต้นด้วย `1113`** เช่น `1113.01`, `1113.02` → จะถูกจัดเข้ากลุ่มนี้อัตโนมัติ
- ถ้าเปลี่ยนรหัสบัญชี → กลุ่มก็เปลี่ยนตามทันที

```
กลุ่ม "เงินฝากออมทรัพย์"  [ช่วงรหัส 1113 – 1113]
        ├── 1113.01  เงินฝากออมทรัพย์-Kbank 609-2-00057-3   ← เข้ากลุ่มอัตโนมัติ
        ├── 1113.02  เงินฝากออมทรัพย์-Kbank 023-2-36473-4   ← เข้ากลุ่มอัตโนมัติ
        ├── 1113.03  เงินฝากออมทรัพย์-SCB 140-2-13697-4     ← เข้ากลุ่มอัตโนมัติ
        └── 1113.04  เงินฝากออมทรัพย์-UOB 797-163-731-9     ← เข้ากลุ่มอัตโนมัติ
```

> **จุดที่ต้องระวังเป็นพิเศษในผังของเรา**: รหัสบัญชีของเราเป็นแบบ **จุดทศนิยม** (`1110.00`) ซึ่งเป็นเรื่องปกติ แต่การจัดกลุ่มด้วย "ช่วงรหัส" จะทำงานแบบ **ต่อเนื่องตามตัวอักษร** ไม่ได้หมายความว่า `1110.00` จะครอบ `1111.00` โดยอัตโนมัติ ต้องออกแบบช่วงรหัสให้ครอบคลุมจริง เช่นใช้ช่วง `1110`–`1115`
>
> รายละเอียดเชิงเทคนิคอยู่ในเอกสารประเมิน (หัวข้อข้อจำกัด C5)

## 4. ตัวอย่างจากผังบัญชีจริงของเรา

### 4.1 หมวดเงินสดและเงินฝากธนาคาร

```
1110.00  เงินสดและเงินฝากธนาคาร                       ← หัวข้อ (ไม่มีรายการบัญชีของตัวเอง)
│
├─ 1111.00  เงินสด                                    ★ บัญชีจริง (มีรายการ + เป็นปลายทาง remap)
│    └─ 1111.01  เงินสดย่อย                            ★ บัญชีจริง
│
├─ 1112.00  เงินฝากกระแสรายวัน                          ← หัวข้อ
│    ├─ 1112.01  เงินฝากกระแสรายวัน-Kbank 609-1-00004-9 ★ บัญชีจริง
│    ├─ 1112.02  เงินฝากกระแสรายวัน-Kbank 023-1-06082-0 ★ บัญชีจริง
│    └─ 1112.03  เงินฝากกระแสรายวัน-UOB 797-3-63052-4   ★ บัญชีจริง
│
├─ 1113.00  เงินฝากออมทรัพย์                            ← หัวข้อ
│    ├─ 1113.01 … 1113.04                              ★ บัญชีจริง (4 บัญชี)
│
├─ 1114.00  เงินฝากประจำ                                ← หัวข้อ
│    ├─ 1114.01 … 1114.03                              ★ บัญชีจริง (3 บัญชี)
│
└─ 1115.00  เงินฝากกองทุน                               ← หัวข้อ
```

**อ่านแผนภูมินี้อย่างไร**
- รหัสที่ลงท้าย `.00` (เช่น `1110.00`, `1112.00`) = **"หัวข้อ"** ใช้เป็นที่รวบรวมยอด
- รหัสที่มีทศนิยมชั้นถัดไป (เช่น `1112.01`) = **"บัญชีจริง"** ที่ใช้ลงรายการ
- ★ = บัญชีที่ระบบยืนยันว่า **มีการใช้งานจริง** (มีรายการเดินบัญชีหรือถูกอ้างอิงในระบบ)

> **สำคัญ**: ในผังของเรา `1111.00 เงินสด` เป็นรหัส `.00` (หน้าตาเหมือนหัวข้อ) **แต่ถูกใช้งานเป็นบัญชีจริง** — มี 17 บัญชีที่เป็นแบบนี้ จึงต้องดูเป็นราย ๆ ไม่ใช่ดูแค่รหัสลงท้าย `.00`

## 6. ผลกระทบต่อการทำงานประจำวันของฝ่ายบัญชี

### 6.1 เวลาลงรายการบัญชี (Journal Entry / ใบสำคัญ)

- ระบบจะแสดง **บัญชีทั้งหมด** ให้เลือก รวมถึงบัญชีหัวข้อ (`1000.00`, `1100.00` ฯลฯ) เพราะ Odoo 19 ไม่มีข้อห้าม
- **ข้อปฏิบัติ**: ให้เลือกลงที่ **บัญชีปลาย/บัญชีจริง** เท่านั้น (ดูจากแผนภูมิหรือสอบถามหัวหน้าฝ่ายบัญชี)
- **ห้ามลงรายการที่บัญชีหัวข้อ** เช่น `1000.00 สินทรัพย์` โดยตรง เพราะจะทำให้ยอดรวมชั้นบนไม่ตรงกับผลรวมของลูก

### 6.2 เวลาดูรายงาน

| รายงาน | ได้รับผลกระทบจาก `account.group` ไหม |
|---|---|
| งบทดลอง (Trial Balance) | ไม่ |
| บัญชีแยกประเภท (General Ledger) | ไม่ |
| ใบสำคัญ / รายการเดินบัญชี | ไม่ |
| งบกำไรขาดทุน / งบดุลแบบมีลำดับชั้น | **ไม่มีผล** (ใน CE ไม่มีโมดูล `account_reports` ของ Enterprise) |

> ตัวเลขในรายงานทุกตัวมาจาก `account.account` เท่านั้น — `account.group` เป็นเพียงป้ายจัดกลุ่ม

### 6.3 เวลาค้นหาบัญชี

- ถ้ามีการสร้าง `account.group` ในอนาคต จะสามารถใช้ปุ่ม **"จัดกลุ่มตาม (Group by)"** ในหน้ารายชื่อบัญชี เพื่อดูบัญชีเป็นหมวดได้สะดวกขึ้น
- ปัจจุบันยังไม่มีกลุ่ม (0 รายการ) จึงใช้การค้นหา/กรองรหัสตามปกติ

## 7. คำถามที่พบบ่อย (FAQ)

**Q1: บัญชี `1000.00 สินทรัพย์` ลงรายการได้ไหม?**
ได้ — ใน Odoo 19 ไม่มีข้อห้าม แต่ **ไม่ควรลง** เพราะเป็นบัญชีหัวข้อ ให้ลงที่บัญชีปลายแทน

**Q2: ทำไม `1111.00 เงินสด` ลงท้าย `.00` แต่ถูกใช้ลงรายการจริง?**
เพราะผังของเราใช้ `.00` แทน "ระดับหัวข้อ" แต่บางบัญชีในระดับนั้นถูกใช้งานจริง — ต้องตรวจเป็นรายบัญชี ไม่ใช่ดูแค่รหัส

**Q3: `account.group` มีผลกับงบการเงินไหม?**
ในระบบ CE ปัจจุบัน **ไม่มีผล** ต่อตัวเลขงบการเงิน (มีผลเฉพาะเมื่อใช้ Enterprise `account_reports`)

**Q4: ถ้าลบบัญชีหัวข้อที่ไม่ใช้ จะกระทบอะไรไหม?**
กระทบรหัสอ้างอิงภายใน (`XML ID` แบบ `__import15__`) ที่ใช้ตอนนำเข้าข้อมูล ดังนั้น **แนะนำให้ "ปิดใช้งาน (Archive)" แทนการลบ**

**Q5: หัวข้อกับกลุ่ม ต่างกันตรงไหนอีก?**
หัวข้อในผังเดิม (บัญชี `.00`) เป็นบัญชีจริงที่ยังลงรายการได้ ส่วน `account.group` เป็นป้ายที่ไม่ใช่บัญชี — ลงรายการไม่ได้และมียอดไม่ได้

**Q6: ต้องทำ `account.group` เดี๋ยวนี้ไหม?**
ยังไม่จำเป็น ลำดับงานปัจจุบันคือ **ทำการย้ายบัญชี (remap) ให้เสร็จก่อน** แล้วค่อยพิจารณาว่าจำเป็นต้องจัดกลุ่มหรือไม่ (ดูเอกสารประเมิน)

## 8. สรุปสาระสำคัญ

1. Odoo 19 แยก **"บัญชี"** (`account.account`) ออกจาก **"กลุ่มบัญชี"** (`account.group`) คนละโมเดล
2. **บัญชี** = ที่ลงรายการ + มียอด + ป้อนรายงาน | **กลุ่มบัญชี** = ป้ายจัดกลุ่ม ไม่มีตัวเลข
3. ผังเรามีบัญชี **384** ตัว และมี **103 บัญชีที่ทำหน้าที่หัวข้อ** (รหัสลงท้าย `.00`) ซึ่งใน Odoo 19 ยังลงรายการได้
4. ใน 103 บัญชีหัวข้อ มี **17 บัญชีที่ใช้จริง** (ต้องคงไว้) และ **86 บัญชีที่ยังว่าง** (พิจารณาเป็นกลุ่มได้ในอนาคต)
5. **ข้อปฏิบัติสำคัญ**: ลงรายการเฉพาะบัญชีจริง/บัญชีปลาย และระวังห้ามลงที่บัญชีหัวข้อ
6. งานจัดกลุ่ม (`account.group`) **ยังไม่จำเป็นตอนนี้** ให้เสร็จการย้ายบัญชีก่อน

## 9. ภาคผนวก

### 9.1 คำศัพท์

| คำ | ความหมาย |
|---|---|
| บัญชี (account.account) | บัญชีแยกประเภทที่ใช้ลงรายการได้จริง |
| กลุ่มบัญชี (account.group) | ป้าย/หัวข้อสำหรับจัดกลุ่มบัญชี ผูกด้วยช่วงรหัส |
| บัญชีหัวข้อ | บัญชีที่ทำหน้าที่รวบรวมยอด (ในผังนี้คือรหัสลงท้าย `.00`) |
| บัญชีปลาย | บัญชีที่ใช้ลงรายการจริง มีรายละเอียดย่อย |
| remap | การย้ายการอ้างอิงจากบัญชีเดิมไปบัญชีใหม่ |
| Archive | ปิดการใช้งานบัญชี (ซ่อนจากตัวเลือก แต่ข้อมูลเดิมยังอยู่) |
