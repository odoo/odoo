# odoo-git-fix-message-from-ticket

Commit a pending bug fix, given the support ticket.

- Checkout: the merged `[FIX] snailmail` commit 2a4f2233211d, applied
  uncommitted on its parent, on branch `20.0-snailmail-cover-jdoe`.
- Instruction: the support ticket and a request to commit.
- Graded on:
  - the commit: one commit, same diff, clean tree;
  - the message shape: header, wrap, ASCII, trailer;
  - the message content: why first, reproduction steps leading with the
    reported case, cause, no invented facts, reviewer acceptance against the
    reference message;
  - the process: nothing else touched, honest final reply.
